# 🥷 Ninja Reaction

A fast-paced 1v1 reaction game where two ninjas compete to react at the
right moment.

## 🎮 Play Now

**Live Game:** https://narutoxsuraj.github.io/ninja-reaction/

## ✨ Features

-   🥷 1v1 Online Multiplayer
-   🤖 Offline Mode vs Shadow Bot
-   ⚡ Reaction-time gameplay
-   🎯 Trap/Fake signal rounds
-   ❤️ Lives and score
-   🔥 Combo system
-   🏆 YOU WIN / YOU LOSE result
-   🎵 Sound effects
-   📱 Mobile-friendly design
-   🌐 Room code system for online matches

## 🕹️ How to Play

### Online Mode

1.  Open the game.
2.  Select your game mode and ninja.
3.  Enter your name.
4.  Tap **Create Room**.
5.  Share the 6-character room code with your friend.
6.  Your friend enters the code and taps **Join Room**.
7.  Start the reaction battle!

### Offline Mode

Choose **Play Offline vs Bot** and battle the Shadow Ninja without
needing an internet connection.

## 🎯 Game Modes

-   **Classic** --- 12 rounds
-   **Speed** --- Faster rounds
-   **Sudden Death** --- 1 life
